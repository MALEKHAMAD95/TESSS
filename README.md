## 🎯 لوحة التحكم الرئيسية

لوحة التحكم هي الصفحة الرئيسية للنظام وتعرض ملخصاً شاملاً لجميع الإحصائيات والأنشطة.

### المكونات الرئيسية:

| المكون | الوصف |
|--------|-------|
| **إجمالي المرضى** | عدد المرضى المسجلين في النظام |
| **الطاقم الطبي** | عدد الأطباء المسجلين |
| **حجوزات اليوم** | عدد المواعيد المحجوزة لليوم الحالي |
| **المنتجات** | عدد المنتجات المسجلة في المخزون |
| **إيرادات الشهر** | إجمالي الإيرادات المالية للشهر الحالي |

### الإجراءات السريعة:
- ➕ **حجز جديد** - إضافة موعد جديد للمريض
- 👤 **مريض جديد** - تسجيل مريض جديد في النظام
- 📦 **إضافة منتج** - إضافة منتج أو خدمة جديدة

### التقويم والحجوزات:
- عرض الحجوزات حسب التاريخ
- تنقل سهل بين الأيام والأسابيع
- عرض تفاصيل الحجوزات لكل يوم

### آخر المرضى:
- قائمة بأحدث المرضى المسجلين
- عرض الاسم ورقم الهاتف وتاريخ التسجيل

## 🏢 إدارة الفروع

قسم إدارة الفروع يتيح لك إدارة جميع فروع العيادة أو المؤسسة الطبية.

### الوظائف المتاحة:

#### عرض الفروع
- عرض جميع الفروع المسجلة
- البحث عن فرع بالاسم أو العنوان
- عرض حالة كل فرع (نشط/غير نشط)

#### معلومات الفرع:
| الحقل | الوصف |
|-------|-------|
| **اسم الفرع** | الاسم التعريفي للفرع |
| **عنوان الفرع** | العنوان الجغرافي الكامل |
| **رقم الهاتف** | رقم التواصل مع الفرع |
| **عدد الموظفين** | إجمالي الموظفين في الفرع |
| **المبيعات** | إحصائيات المبيعات للفرع |
| **الأداء** | نسبة أداء الفرع |
| **المدير المسؤول** | اسم مدير الفرع |

#### إضافة فرع جديد
1. انقر على زر "إضافة فرع جديد"
2. أدخل معلومات الفرع الأساسية
3. حفظ الفرع

#### تعديل الفرع
- تعديل بيانات الفرع
- تغيير حالة الفرع
- تحديث معلومات الاتصال

### الصلاحيات:

- **SALES** - صلاحيات المبيعات والحجوزات

### العمليات المتاحة:
- ➕ إضافة موظف جديد
- ✏️ تعديل بيانات الموظف
- 🗑️ حذف الموظف
- 📥 تصدير البيانات

### فلترة الموظفين:
- الكل
- نشط
- غير نشط
- البحث بالاسم أو اسم المستخدم
